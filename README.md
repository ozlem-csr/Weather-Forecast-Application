# Weather Forecast Application

A graphical weekly weather application developed using procedural programming and the BGI graphics library.

## Features
- Display weekly weather conditions and temperatures.
- Show weather animations.
- Update daily weather conditions.
- Store weather data in text files.
- Back up previous weather information.

## Technologies
- C / C++ (Procedural Programming)
- BGI Graphics Library
- Structures
- File Handling

## How to Run
1. Open the project in Dev-C++.
2. Configure the BGI graphics library.
3. Select the 32-bit Release configuration.
4. Compile and run the project.
